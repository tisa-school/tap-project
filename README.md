# Creeper case downloads

**Use [Creeper-case-revision.zip](Creeper-case-revision.zip) for the latest fit prototype.** Extract the ZIP on your computer, read its README, and print the small hub-footprint test ring before attempting the large case sections.

The revision adds a top viewing bay for the micro:bit red LED display, an enlarged hub bay, a wider camera opening, four smaller head/body sections and a separate bottom tray. It includes an offline 3D viewer and official hardware-dimension references. All five case parts fit the Bambu P1S build envelope in their supplied orientations.

**This is not a final fitted or print-tested enclosure.** Manufacturer documentation confirms the likely hardware footprints, but hub height, camera thickness, exact connector positions, lens field of view, mounting and seam fasteners still require a physical fit check. Supports have not been verified in Bambu Studio. The proposed layout rehouses the electronics; it does not fit over the original unmeasured brick tower/base.

`Creeper.stl` is the earlier one-piece figurine. It is about 290 mm tall and exceeds the P1S build height; it also lacks the revised micro:bit viewing opening. Do not use that earlier file for the electronics enclosure.
